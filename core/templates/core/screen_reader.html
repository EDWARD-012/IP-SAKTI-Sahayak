Screen Reader Accessibility

GIGW 3.0 compliant accessibility information.

Keyboard Navigation

  • Tab — Move to next interactive element
  • Shift+Tab — Move to previous interactive element
  • Enter / Space — Activate buttons and links
  • Ctrl+Enter — Submit chat question (in chat interface)
  • Esc — Close expanded sections

Skip Links

A "Skip to Main Content" link appears at the top of every page when focused. Press Tab on page load to reveal it.

Language Selection

The language selector is in the navigation bar. Use Tab to reach it, arrow keys to select a language, and Enter to confirm. The page reloads in the selected language.

Font Size Controls

The accessibility bar at the top offers A+, A, A- controls for increasing, resetting, or decreasing the base font size. Your preference persists across pages.

Chat Interface

In the chat interface:

  • The answer area has role="live" and announces new answers to screen readers automatically.
  • Evidence labels are announced with full text (e.g. "Strong evidence").
  • Citations can be expanded with Enter or Space.
  • The "thinking" animation is hidden from screen readers (aria-hidden="true").
