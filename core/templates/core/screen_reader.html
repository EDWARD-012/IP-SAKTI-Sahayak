Screen Reader Access

This website follows Guidelines for Indian Government Websites (GIGW) accessibility practices and is designed to work with assistive technologies such as screen readers.

Compatible screen readers

Visitors with visual impairments can access IP-SAKTI Sahayak using assistive technologies. The following screen readers are commonly used with Indian government websites:

Information about different screen readers
Screen Reader Website Free / Commercial
Non Visual Desktop Access (NVDA) nvaccess.org Free
JAWS (Job Access With Speech) freedomscientific.com Commercial
Narrator (Windows) Microsoft Support Free (built-in)
VoiceOver (Apple) apple.com/accessibility Free (built-in)
TalkBack (Android) Google Accessibility Free (built-in)

How to use this site with a screen reader

  • Press Tab on page load to reveal Skip to Main Content, then press Enter.
  • Use heading navigation (for example NVDA: H / Shift+H) to move between sections.
  • Font size controls (A+ / A / A-) and theme toggle are in the accessibility bar at the top of every page.
  • Language can be changed from the main navigation; the page reloads in the selected language.

Keyboard shortcuts

  • Tab — Next interactive element
  • Shift+Tab — Previous interactive element
  • Enter / Space — Activate buttons and links
  • Enter — Submit the chat question when focus is in the Ask field
  • Esc — Close expanded citation panels (where supported)

Chat assistant announcements

  • After you submit a question, a live region announces that your question was received and that sources are being searched.
  • When the answer arrives, focus moves to the answer region and the evidence status is announced.
  • Evidence labels are read in full (for example “Strong evidence”).
  • Expand citations with Enter or Space on the citations button.
  • Decorative loading graphics are hidden from assistive technology; status text is announced instead.
