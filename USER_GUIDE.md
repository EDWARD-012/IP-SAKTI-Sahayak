# IP-SAKTI Sahayak — User Guide

IP-SAKTI Sahayak provides source-based general information about intellectual
property, biodiversity/ABS and regulatory topics related to Ayurveda.

Live demo: https://ip-sakti-sahayak-production-4c21.up.railway.app


It does **not** replace a patent agent, lawyer, regulator or medical
professional.

## Before you start

Do not enter:

- a secret formulation or manufacturing process
- an unpublished patent draft
- patient/medical information
- Aadhaar, phone, address or identity documents
- confidential company/client material
- paid database credentials

## Choose your language

The application suggests a language from your browser. Confirm it or select
another language manually. The manual selection always wins.

Language support may be labelled:

- **Verified:** fully tested
- **Pilot:** tested on a smaller question set
- **Beta:** best effort; verify with the original source

Official source quotations remain in their original language so that section
numbers and legal text are not silently changed by translation.

## Choose jurisdiction

Use **India** for Indian statutes, rules, regulators and registries. Use
**International** only for the supported treaty-level overview. It does not
provide the domestic law of a foreign country. If a question mixes both,
the answer keeps the two evidence sets visibly separate.

## Use the formulation wizard

The wizard asks about:

- whether the formulation/process comes from an authoritative classical text
- modifications to ingredients, process, dosage or intended use
- therapeutic versus food/cosmetic claims
- biological-resource and traditional-knowledge inputs
- intended India/international context

You can answer "not sure," go back and change an answer. The result is a
preliminary information route, not a definitive legal classification.

## Ask useful questions

Good examples:

- "Explain the general Section 3(p) issue for a classical formulation."
- "Which official sources discuss Ayurveda Aahara?"
- "What is TKDL used for?"
- "What information may matter for an ABS enquiry?"
- "Explain the difference between Indian law and the WIPO GRATK Treaty."

Avoid questions that ask the assistant to:

- guarantee a patent or litigation outcome
- diagnose or prescribe medicine
- calculate a final legal fee/deadline from missing facts
- provide country-specific foreign-law advice outside the supported corpus

## Read the answer safely

1. Check whether the evidence label says **Strong evidence**,
   **Limited evidence**, or **Unable to answer from verified sources**.
2. Open each citation supporting an important claim.
3. Check authority, section and effective/updated date.
4. Follow the official link for the current source.
5. Consult the relevant authority or qualified professional before acting.

- **Strong evidence:** the important claims have direct, current support in
  verified corpus excerpts.
- **Limited evidence:** support is partial, qualified or conflicting; inspect
  the cited text and escalate before acting.
- **Unable to answer from verified sources:** the active corpus cannot safely
  support an answer. This is a refusal, not a negative legal conclusion.

## Common messages

| Message | Meaning |
|---|---|
| Not enough verified evidence | The corpus cannot safely answer; narrow the question |
| AI summary unavailable | The model failed, but verified source sections are available |
| Model busy | Another local request is running; wait or retry |
| Translation unavailable | Use the verified English/Hindi result |
| Source may be stale | Check the official update link before relying on it |
| Unsupported jurisdiction | The assistant does not cover that country's domestic law |
| Potential sensitive information | Remove personal identifiers, unpublished inventions or confidential material before submitting |

## If something goes wrong

- Refreshing will not improve an unsupported answer; rewrite the question with
  product type, jurisdiction and intended use.
- If the model is unavailable, use the evidence cards and official links.
- If a citation link is temporarily down, the locally stored official excerpt
  and its retrieval date remain visible.
- Use feedback to flag a wrong citation, unclear answer, translation problem or
  outdated source.

## Privacy

Chat history is not retained by default. Use **Delete session** to clear local
conversation state. The application records only minimal technical audit data
such as request ID, a keyed non-plain-text query fingerprint, corpus version,
cited chunk IDs, outcome and latency unless the deployment explicitly
discloses otherwise.

Use **About the corpus** to see included authorities, active corpus version,
last-updated dates and known coverage limits.

## Scope reminder

This assistant gives information from a limited, versioned corpus. A disclaimer
does not make an unsupported answer safe, so the system intentionally refuses
when jurisdiction, facts, dates or verified evidence are insufficient.
